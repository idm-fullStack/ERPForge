# 4. Требования к системе

## 4.1. Функциональные требования

Система должна обеспечивать:

| ID | Требование | Домен |
|----|------------|-------|
| FR-01 | Аутентификация и авторизация (JWT + 2FA) | Security |
| FR-02 | Полный аудит всех действий | Audit Log |
| FR-03 | Управление подписками и платежами | Billing |
| FR-04 | Ведение бухгалтерского учёта (проводки, регистры) | Accounting |
| FR-05 | Управление юридическими лицами | Enterprises |
| FR-06 | Расчёт налогов (УСН/ОСНО) | Tax |
| FR-07 | Управление лидами и сделками (CRM) | CRM |
| FR-08 | Кадровый учёт и расчёт зарплаты | HRM |
| FR-09 | Юнит-экономика (CAC, LTV, COGS) | Product Analysis |
| FR-10 | Интеграция с банками и 1С | Integrations |
| FR-11 | Генерация отчётов (P&L, баланс) | Reporting |
| FR-12 | Уведомления (Email, SMS, Telegram) | Notifications |
| FR-13 | Бизнес-процессы (согласования) | Workflow |
| FR-14 | Миграция с 1С/SAP | Migration |
| FR-15 | AI-ассистент (чат-бот, прогнозы) | AI |

## 4.2. Нефункциональные требования

| Категория | Требование |
|-----------|------------|
| Производительность | Время ответа < 100ms для 95% запросов |
| Доступность | 99.9% (простой < 8 часов в год) |
| Безопасность | ГОСТ Р 56545-2015, 152-ФЗ |
| Масштабируемость | Горизонтальное масштабирование |
| Целостность | ACID, аудит всех изменений |
