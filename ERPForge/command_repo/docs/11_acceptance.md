# 11. Порядок контроля и приёмки

## 11.1. Критерии приёмки

- Прохождение всех автотестов (Karate + Schemathesis)
- Соответствие OpenAPI-контракту
- Наличие документации (MkDocs)
- Проведение пентеста (OWASP ZAP)
- Демонстрация заказчику

## 11.2. Порядок сдачи-приёмки

1. Демонстрация разработанной системы
2. Передача документации
3. Подписание акта сдачи-приёмки
