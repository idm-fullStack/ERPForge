# 9. Тестирование

## 9.1. Виды тестов

| Тип | Инструмент | Назначение |
|-----|------------|------------|
| Юнит | cargo test / pytest | Проверка отдельных модулей |
| Интеграционные | pytest | Взаимодействие модулей |
| E2E | Karate DSL | Бизнес-сценарии |
| API-контракты | Schemathesis | Property-based тестирование |
| Безопасность | OWASP ZAP | Сканирование уязвимостей |

## 9.2. Критерии приёмки

- 100% прохождение всех тестов
- Покрытие кода > 80%
- Отсутствие критических уязвимостей
- Соответствие OpenAPI-контракту
