# Vision: ERPForge — Масштабируемая ERP для бизнеса

## Миссия
Создать доступную, гибкую и производительную ERP-систему, которая заменяет 1С и SAP для малого и среднего бизнеса.

## Ценности
- **Масштабируемость** — от ИП до холдинга
- **Прозрачность** — полный аудит и понятная юнит-экономика
- **Скорость** — Rust-ядро для транзакций, Python для бизнес-логики
- **Интеграции** — 1С, банки, маркетплейсы "из коробки"

## Ключевые цели (2026-2027)
| Цель | Срок | Метрика |
|------|------|---------|
| MVP Релиз | Q3 2027 | 10 платящих клиентов |
| Юнит-экономика | Q4 2026 | Авторасчет COGS, маржинальности |
| Интеграция с 1С | Q1 2027 | Экспорт/импорт данных |
| White Label | Q2 2027 | Первый белый бренд для клиента |
| AI Ассистент | Q3 2027 | Чат-бот для бухгалтера |

## Конкурентное преимущество
- Rust vs 1С (10x быстрее проводок)
- Юнит-экономика (чего нет в 1С/SAP)
- SaaS-модель (без дорогих внедрений)
- Open API (интеграции без SDK)
